## Documentation rule

- `docs/context.md` is the living project context and session handoff file. Read it before starting work.
- Maintain `docs/context.md` continuously: after any meaningful change, update its **Session Handoff** block and **Context Update Log**.
- Record project decisions in the **Decision Log** in `docs/context.md` (and in `docs/doc.md` §12 when requirements change).
- `docs/doc.md` is the living SRS. Keep requirement IDs stable and update it when scope or requirements change.
- Never write secrets, API keys, or real credentials into documentation.
